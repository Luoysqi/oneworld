一个让MC更优雅的世界观，这个Fabric模组把我的世界原版的三个维度融合到了一个世界中，且为了防止玩家过于容易的进入末地和下界，我在不破坏原版的条件下做了一些额外内容。


Mod 介绍：

增加了一些小细节；

从上到下依次是末地、主世界、热区、下界；

搭方块能更高，世界整体变得超级厚；

从主世界向上搭方块去末地时会有幻翼试图阻止你；

从主世界向下挖方块去下界时有厚厚的黑曜石(热区)阻挡，且会着火(钻石套或合金装备可免疫)；

在配置文件 oneworld.txt 中关闭 enableRestrictions 可以取消以上两条的限制，默认开启；

在配置文件中的第二个配置项endNightSky，开启后末地为永夜，关闭则末地昼夜更替，默认开启；

在配置文件中 vanillaNetherLight 开启下界后亮度和原版一样，关闭后亮度更暗，默认开启；

往上搭到末地时模组会把末地的天空强制替换为原版末地的天空，若卡顿可以关闭光影或者关闭配置文件中的endNightSky；

热区的下方和下界的上方有一片很大空旷区(照顾原版体验，用来建造生电机器或下界高速通道)

支持模组菜单，模组可以热更改配置项。


A more elegant worldview for Minecraft. This Fabric mod merges the three dimensions of vanilla Minecraft into a single world, and to prevent players from entering the End and the Nether too easily, I have added some extra content without breaking the vanilla experience.


Mod Introduction:

Some small details have been added;

From top to bottom, the order is: the End, the Overworld, the Hot Zone, and the Nether;

You can stack blocks higher, and the world becomes super thick overall;

When building upward from the Overworld to reach the End, phantoms will try to stop you;

When digging downward from the Overworld to reach the Nether, thick layers of obsidian (Hot Zone) will block your way, and you will be set on fire (a full diamond armor set or netherite equipment can grant immunity);

Disabling enableRestrictions in the configuration file oneworld.txt can remove the restrictions of the above two entries; this option is enabled by default;

The second configuration option in the configuration file, endNightSky, makes the End eternally night when enabled, while disabling it gives the End a day-night cycle; this option is enabled by default;

When vanillaNetherLight is enabled in the configuration file, the Nether brightness is the same as vanilla; when disabled, the brightness is darker; this option is enabled by default;

When building upward to the End, the mod forcibly replaces the End's sky with the vanilla End sky; if lag occurs, you can disable shaders or disable endNightSky in the configuration file;

Below the Hot Zone and above the Nether, there is a large open area (to preserve the vanilla experience, for building technical farms or Nether highways);

Mod Menu is supported, and the mod's configuration options can be hot-reloaded.
